# &#x20;test 6— User Guide

Northwind Analytics turns a plain-English question into a working dashboard. You describe what you need, and it builds a real page your colleagues can open in a browser, along with somewhere to keep the data behind it.

This guide takes you from your first sign-in to running your own reports. No coding, and no prior knowledge assumed.

:::tip[Demo content]

This is a proof-of-concept documentation site. The product described here is fictional — the pages exist to demonstrate how a visual editor handles headings, callouts, tables, images and code blocks.

:::

## Who this is for

Anyone in the organisation who needs to answer a question with data — you do not need to be technical, and you will not be asked to write any code.
